# 插件与功能清单

## 已实现的正式插件

- `plugin-layout-panes`：主区域分栏，支持单栏、双栏、四栏。
- `plugin-layout-views`：管理侧栏视图切换。
- `plugin-inspector`：右侧详情区和信息/历史标签页容器。
- `plugin-file-browser`：浏览文件夹；列表、网格、表格视图；导航、排序、标签显示。
- `plugin-view-file-tree`：目录树。
- `plugin-view-favorites`：收藏与书签。
- `plugin-view-tags`：创建、编辑、删除标签和管理标签成员。
- `plugin-file-ops`：复制、移动、删除、重命名、新建、打开文件和定位文件。
- `plugin-file-details`：查看文件属性和 BLAKE3 哈希。
- `plugin-file-history`：显示文件变更的哈希与元数据快照；当前不能恢复旧版本。
- `plugin-preview`：预览文本、代码、Markdown、图片、PDF、音视频、Office 文件和压缩包。
- `plugin-search`：按名称搜索已建立索引的文件和文件夹。
- `plugin-context-menu`：提供统一右键菜单，菜单项由其他插件贡献。
- `plugin-command-palette`：搜索命令和文件，支持快捷键 `Ctrl+Shift+P`。
- `plugin-storage-analysis`：扫描目录并分析磁盘空间占用。
- `plugin-settings`：切换主题、启停插件和打开插件设置页。

## 已实现的开发辅助插件

- `plugin-mock-data`：提供模拟文件和压力测试数据。
- `plugin-devtools-log`：查看插件事件和调试日志。
- `plugin-dev-slot-harness`：展示和验证插件插槽。

## 待开发或未完成

- `plugin-windows-thumbnails`：独立的 Windows 缩略图设置与管理插件。Windows 缩略图读取能力已经接入，真实 Windows 效果仍待确认。
- `plugin-history-metadata`：为历史版本保存和显示缩略图、大小、类型等信息；依赖文件历史版本功能。
- `plugin-file-history` 后续功能：Lore 版本管理、版本对比、恢复旧版本。目前暂缓，尚未排期。
- `plugin-file-details` 后续功能：增加更多文件元数据展示。
- `plugin-file-browser` 后续功能：文件浏览快捷键。
- 系统通知：长时间文件操作完成后发送 Windows 通知。
- 窗口状态记忆：保存窗口大小和位置，并限制应用只启动一个实例。
