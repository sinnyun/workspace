### 中间栏对齐与扩展入口

后续批注调整：顶部右侧使用两个显示当前值的下拉按钮，分别选择分栏布局与列表／网格视图；顶部主题切换移除，设置页仍提供跟随系统／亮色／暗色。浏览器验证列表／网格和单栏／双栏菜单选择有效，设置页主题选项可见，相关三个模块类型检查与构建通过。

- [两个下拉按钮与精简顶部栏](toolbar-dropdowns.jpg)

依据后续说明，分栏选择收进 `plugin-layout-panes` 贡献到 `topbar-zone` 的一个扩展按钮，位于地址栏之后、视图模式之前。点击打开单栏／左右双栏／四栏菜单，主内容区不再有分栏工具条。会话行、工具栏与内容区共用 16px 水平留白；卡片行取消额外 8px 水平缩进，列数按完整内容宽度计算。

浏览器实测 1200×800：目录条、分组条、首列卡片左边界一致，末列卡片与分组条右边界相差不足 1px。900×650 工具栏无横向溢出，地址输入框宽 102px；双栏和四栏分别显示 2／4 个面板，菜单回到单栏成功。相关模块类型检查、构建和契约检查通过，浏览器错误日志为空。

- [中间栏对齐后的整体界面](center-aligned-light.jpg)
- [分栏插件扩展菜单](layout-extension-menu.jpg)

以 `docs/界面布局.jpg` 为区域位置依据，左上品牌区跨活动栏与文件树，中间会话标签和导航占两行，右侧详情从工作区顶部贯穿到底部状态栏。设置在左侧底部，调试抽屉默认关闭。单栏隐藏重复的面板标题与地址栏，详情依次展示选中标题、页签、预览、属性、扩展预留区。未增加尚未实现的文件操作按钮。

导航由文件浏览插件贡献到既有 topbar-zone，文件路径和历史仍留在插件内。插件内部导航快照测试 2 项通过；浏览器实际检查了顶部地址输入、后退、双栏、关闭面板回退与会话切换。1440×900 明暗色截图核对区域位置。相关模块类型检查、生产构建、TS/Rust 契约检查通过，浏览器错误日志为空。

根据实际截图定位并修复：侧栏视图缺少高度传递导致目录树只有 80px 高；文件浏览初始空数据时没有注册宽度监听，导致网格一直停留在两列；窄窗口主题文字隐藏规则误隐藏图标。网格按面板宽度排布，虚拟行估算与实际高度同步：列表 36px、分组 32px、卡片行 156px（卡片 144px + 上下间距 12px）。
