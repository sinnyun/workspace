# `plugin-storage-analysis` · 空间分析

**状态：规划。** 在单独 pane 中扫描用户选定的目录并以 treemap 展示体积占用；不承担通用浏览/删除操作。

## 用户功能与显示

- 选择根目录后启动扫描；显示已扫描目录/文件和进度（有真实总数才显示百分比），支持取消、暂停与重新扫描（若对应后端能力支持）。
- treemap 显示目录/文件相对占用、名称和大小；点击块下钻，面包屑返回上层；小文件合并进“其他”时必须保留明细入口。
- 空目录、权限跳过、循环符号链接、文件删除/变化、磁盘读取失败分别说明；图表响应式调整，不将 10 万节点全部一次渲染为 DOM。
- 下钻/上钻轻量缩放约 180–240ms；减少动态效果立即切换。图表色彩从 Mantine token 映射，色彩之外仍显示文本/尺寸信息。

## 数据处理、存储与交流

- 使用 `sys.disk` 获取卷空间元信息，`fs.list`/规划中的并行遍历能力累计文件夹大小；避免对每个节点再调用 `fs.stat`。循环/权限边界由 scanner 处理并计数。
- 数据为分层聚合 DTO（path、direct/aggregate size、children count、扫描错误数），不写入全局元状态；可缓存结果，但 key 必须含根路径、修改时间/扫描版本，明确失效。
- 在 `pane-slot:*` 注入自有可视化，不直接修改 file-browser 当前目录；点击“在文件浏览中打开”通过明确导航 Ref/事件协作。
- `sys.disk`/遍历若仍规划中，进入实现前需冻结能力、进度、取消和错误 DTO；不能把扫描进度伪装为 `file:operation:progress`。

## 验收

小/大目录、权限跳过、符号链接循环、取消、扫描期间变更、缓存失效、不同单位格式、空结果、趋势/容量不一致，以及点击下钻/跳转普通浏览器保持状态。
