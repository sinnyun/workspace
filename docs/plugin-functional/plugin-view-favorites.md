# `plugin-view-favorites` · 收藏视图

**状态：现有。** 提供活动栏入口和 `nav-panel:favorites`，包含主页/常用位置以及用户收藏。

## 功能与交互

- 点击主页或收藏行发出导航选择；焦点存在时可将当前文件/目录加入收藏；重复收藏同一路径更新名称/类型而不产生第二条；每条可移除。
- 空列表说明如何收藏；存储内容无法解析时显示空态并提供可理解的恢复提示；收藏路径不存在时保留记录并标成不可用，提供移除或重新定位操作（重新定位是否实现时由产品确认）。
- 行名过长截断、悬停可读全名；移除按钮单独命名，不应误触发打开。删除立即更新列表并轻量淡出。

## 数据与交流

- 主页路径调用 `fs.home`；home 加载中/失败有独立状态。收藏行由插件存储生成，数据为 `{path,kind,name}`。
- 当前存储：`fm.view-favorites.v1`，本插件独占 localStorage。加载时验证数组、path/name/kind；写入失败提示本次会话可用但不会记住。
- 添加当前焦点读取 `host.getState().focusRef`；点击条目发 `sidebar:selection:changed` 的不透明 Ref 给 file-browser；不直接调用另一个插件，不写基座状态。
- 用户切入收藏页通过 `sidebar:view:changed {viewId:"favorites"}`；焦点变化只用于启用/禁用“收藏”入口。
- 对收藏条目注册 `contextMenu` 动作“打开/定位”和“移除收藏”；动作由本插件读取并更新自己的收藏数据。收藏页空白区可注册“将当前焦点加入收藏”，无有效焦点时隐藏/禁用。右键面板由 `plugin-context-menu` 统一呈现。

## 验收

主页加载、空列表、加入/重复加入/移除、损坏存储、不可用路径、storage quota error、切换会话/视图都不丢错误焦点；点击收藏能驱动每个浏览栏按既定导航策略。
