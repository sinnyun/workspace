# `plugin-archive` · 压缩包浏览与解压

**状态：已取消，不纳入当前插件清单或开发路线。** 原规划是将 zip/tar/7z 提供为只读虚拟目录并允许安全解压；不修改归档内部成员。本文件保留作决策记录，后续若重新提出需重新评估能力边界、归档安全和用户场景。

## 功能与交互

- 在浏览器对归档文件执行“打开为归档”后，主视图区以目录/文件列表形式浏览条目，路径 breadcrumb 仅表示归档内部层级；上级返回归档根，关闭/退出回普通文件系统。
- 列出名称、目录层级、未压缩/压缩大小和支持时的时间戳；大归档分页/虚拟化。损坏/加密/不支持格式有专门错误；加密档可提示密码但不得日志记录密码。
- 解压前选择真实目标目录、冲突策略、选择范围；显示实际进度/文件计数，可取消并显示部分结果。

## 数据和安全边界

- Archive Ref 必须有独立 kind，字段含归档文件 path 与内部 entry path，不能伪装普通 filesystem path；归档列表用 `archive.list`，真实目标读写由 archive/fs 原子能力处理。
- 防止 `../`、绝对路径、盘符/UNC 出口、符号链接逃逸、重复文件名、炸弹大小和嵌套递归。解压前计算展开大小/数量上限；目标目录经用户明确选定。
- 不直接调用 file-browser 内部组件；复用其行数据规范/插槽展示时仍需由明确的共享视图接口提供，不能导入另一个插件。
- `archive.list/extract` 及进度/取消契约需在 Rust 与 SDK 冻结；归档临时缓存由本插件清理，不进用户长期偏好。

## 验收

zip/tar/7z 支持矩阵、空归档、损坏、密码、长路径、路径穿越、重复冲突、大量成员、展开大小限制、取消和部分失败；归档内 Ref 不能触发 `fs.readText` 读到非归档目标。
