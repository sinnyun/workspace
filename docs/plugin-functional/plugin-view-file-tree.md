# `plugin-view-file-tree` · 目录树视图

**状态：现有。** 贡献活动栏入口与 `nav-panel:file-tree`。以懒加载树浏览目录，目录选择驱动 C 区。

## 功能与显示

- 根目录由 `fs.home` 与一次 `fs.list` 建立；目录节点首次展开时才列子项，不递归扫描整个磁盘。折叠不会清掉已加载子树。
- 目录有展开/折叠箭头，文件是叶节点；当前选中状态与 A 区活动图标分别表示“正在看树视图”和“选中某节点”。
- 根加载、子目录加载、空目录、失败/重试需有不同显示状态。空目录占位不是可导航文件；失败行需可再次触发加载。
- 树节点支持 react-arborist 的键盘导航；箭头按钮不抢父行选择；焦点、hover、选中行使用 Mantine 主题态。展开/折叠 120–180ms，减少动态效果时立即变化。

## 数据、存储与交流

- 能力：`fs.home`、`fs.list`。选择目录/文件发 `sidebar:selection:changed {kind,id,sourcePlugin}`；不向 C 区发送目录子树或 metadata。
- 展开节点与已加载目录目前放组件内存，不持久化；视图容器隐藏而不卸载，可在本次运行保留。未来若要跨重启记忆展开路径，需单独定义版本化 key。
- 每个节点以规范化 path 作 id；加载请求按 path 去重，失败后移出 in-flight/loaded 标记以允许重试；返回结果需校验树仍挂载且目标节点存在。
- 本插件不监听全局文件变化以重建整棵树；目录刷新可局部更新展开节点。大目录使用树虚拟化，不发逐节点 stat。

## 验收

启动根目录失败后可重试；空根和空子目录区分；双击/键盘选择路径能驱动浏览器；重复展开只发一次请求；失败重试、快速切视图、插件停用后无残留更新；树项不能触发全盘递归。
