# `plugin-search` · 名称搜索

**状态：已交付（P6-9 / P7-28 / P7-29 / P7-30，2026-10-10 取证；引擎定案见 05 D24）。** 检索已索引的文件夹与文件**名称**，并对命中做打开/定位。本批不含正文级全文。

## 用户入口与显示

- 顶栏 `topbar-zone` 贡献「搜索」按钮，点开是一个**固定 620×640 的浮层面板**，内容在面板内滚动；输入中、索引中、有结果、无结果、索引不完整这几种状态下面板的宽高与位置都不变。
- 输入 **300ms 停手才查**（每敲一个字就查一次，答案会跟着手不停改口）；范围三态 全部/文件/文件夹，旁边一键在「全部索引」与「当前目录」之间切换限定（默认值在设置页，面板顶部随时可改）。
- 结果行与列表行同口径：名称、父目录、目录/文件、大小与修改时间（目录两项为 null，和 `fs.list` 一致）。
- 「取更多」按 `offset` 接下一页（一页 ≤50 条，`SEARCH_MAX_PAGE`=200 封顶）；分页是请求/响应，没有结果事件——路线图里的 `search:results` 已折进 `search.query`（D24）。
- 双击命中 = `shell.openPath` 交给系统默认程序；「打开所在目录」发 `sidebar:selection:changed` 引用，由文件浏览栏自己导航过去——面板不持有第二份"当前目录"。
- 检索词记在模块内存（不落盘）：为了看一眼别处而关掉面板的人，重开时不该从空白重新开始。

## 索引与数据来源

- 引擎是 SQLite **FTS5**（`tokenize='trigram'`）——`rusqlite` bundled 自带，不是新依赖。索引库是宿主数据目录下**独立、可整体重建**的 `search-index.db`：`files(rowid, name, parent, is_dir, size, mtime)` 加对同一行 `name` 建倒排的**外部内容**表，名称文本只存一份。本批只索引**文件名与路径**，正文级全文不在内（D24）。
- 四个能力：`search.status`（只读状态，不遍历任何目录）、`search.query`（分页查询）、`search.index.start`（**只回确认** `{jobId, roots, state}`，进度走事件）、`search.index.cancel`（返回布尔）。
- 进度 `search:index-progress` 按 ≥120ms 节流，**只有真实条目数与耗时，没有百分比**——条目上限让总数事先未知；终态 `search:index-done` 是独立事件（`cancelled: true` → 索引为 `partial`），取消不靠"少了一次进度"猜。
- 中文子串靠 trigram（`unicode61` 会把一整段中文当作一个 token，"报告"和"季度报"都搜不到——这不是偏好）；查询 ≥3 字符走 MATCH，<3 字符退回对 FTS 表的**有界 `LIKE` 扫描**（`SEARCH_TRIGRAM_MIN_CHARS`=3）；索引深度上限 64 层。
- 状态机 `empty / indexing / ready / partial / failed`；`partial`/`failed` 必须显示 provider 给的中文 `detail`，界面同时把结果标为「索引不完整」——把"还没索引到"说成"没有匹配"是契约禁止的谎话。
- 索引是**缓存而非事实源**：任何时刻可删可重建，界面状态不依赖它存在。

## 索引目录与任务（面板内管理）

- 面板第二行管理索引：「选择…」走 `shell.pickDirectory` 定一个目录；「索引」把该目录**补进**索引（不影响其他根目录）；「重建」丢弃现有索引、只索引这个目录。留空 = 主机的默认根目录集合。
- 索引中该处就地变成「取消索引」：在时间片边界有界停下；终态是 cancelled → `partial`，徽标如实说明结果不完整。
- 进度行只有真实数字：「已收录 N 项 · 用时 … · 正在读取 <目录>」；当前目录是显示提示，不是游标。

## 命令与偏好

- 注册命令 `search.open`（打开搜索面板）与 `search.index-current`（索引当前目录，之后自动打开面板看实时进度）——快捷键由基座命令服务统一调度（D25），插件自己不限键。
- 偏好 `fm.search.prefs.v1` = `{scope: "all"|"file"|"dir", withinCurrent: boolean}`，默认 `{all, false}`；损坏回退默认；写失败（隐私模式等）只影响下次打开，不阻断当前会话。
- 贡献 `settings-page:search`，只放**默认值**：默认筛选范围、默认是否限定在当前目录。设置页不改"当前这一次查询"，面板顶部才是即时开关。

## 与其他插件的关系

- 打开命中走 file-browser 的既有约定（引用事件），不改它的内部状态；双击交给系统默认程序。
- 索引库由内核能力持有，库句柄不出内核；**没有搜索后端插件**（D24），前端只编排能力与事件。
