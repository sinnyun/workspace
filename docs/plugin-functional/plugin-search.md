# `plugin-search` · 文件搜索

**状态：规划，全栈；FTS5/Tantivy 引擎待评估。** 提供快速文件名/内容检索、索引维护和结果导航。

## 用户功能与交互

- 从快捷键/Spotlight 命令面板打开搜索；输入词、选择根范围、文件名/内容/类型过滤和是否包含隐藏项；支持清空、取消、再次查询。
- 输入变化采用 debounce，Enter 提交；显示查询中、正在建索引、部分结果、无结果和失败。列表虚拟化，显示路径片段、文件类型、匹配摘要；点击结果定位父目录并聚焦文件。
- 历史查询是否持久化需显式设置；默认不记录查询正文。结果跳转时若文件失效，提示并继续显示其它结果。

## 数据处理与存储

- 后端维护可重建索引，文件遍历来自 `fs.list`；内容抽取按类型/大小/编码白名单执行，不将二进制解释为文本。查询支持取消、限流和部分结果；结果 DTO 含 path/kind/mtime/摘要/匹配位置。
- `file:changed` 触发增量更新或删除索引项；批量扫描显示阶段和可取消状态。索引分区归本插件，记录版本/根路径/更新时间；索引损坏可重建。
- `search.query` 能力及 `search:results` / index progress 事件仍须冻结契约；不可把规划名加入已用 manifest 权限，直到 Rust/SDK 真实实现。

## 插件交流、动效与验收

- UI 请求由本插件发起；结果行点击发 `sidebar:selection:changed` 或带结果 Ref 的导航契约驱动 file-browser，并通过 `focus:changed` 聚焦目标。基座负责提供命令面板壳，命令注册 API 当前尚不存在，须先独立设计。
- 搜索输入即时响应，loading spinner 不抖动结果区域；新查询开始取消/忽略旧查询；结果更新轻量淡入。
- 验收：文件名/内容/范围过滤、取消、索引初始化/增量更新、重复 watcher、损坏重建、大结果、无权限、文件删除、无结果和结果跳转。索引引擎与许可证/性能结论落决策文档。
