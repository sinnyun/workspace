# `plugin-command-palette` · 命令面板

**状态：已交付（P7-30，2026-10-10 取证；分工定案见 05 D25）。** Ctrl+Shift+P 呼出的命令面板：检索并执行各插件注册的命令，也能按名称跳转当前目录里的文件。它是 `command-palette` 槽的**唯一面板提供者**。

## 入口与角色

- 基座只渲染 `command-palette` 槽的出口，**不含任何面板逻辑**；本插件经 `commands.provide()` 领取唯一 launcher，用 Mantine Spotlight 渲染面板——**固定 620×420**，列表内部滚动（内联覆盖库自带的 `max-height: calc(100% - 3.125rem)`），行再多也不改变几何。
- `Ctrl+Shift+P` 本身是一条注册命令 `palette.open`——"面板怎么开"和"插件怎么发命令"走同一条路径，插件不自己挂键盘监听（D25）。
- 面板被停用时，命令与快捷键随插件在基座的卸载清理里一起消失；单提供者形态是刻意的（D25 代价与边界）。

## 行与过滤

- **命令段**：来自基座登记簿的实时清单（谁注册/卸载，面板就地重画），按 descriptor 的 标题/副标题/分组/id 子串过滤；有快捷键的行右侧显示键位。
- **文件段**：输入非空时按**当前目录** `fs.list` 的名称子串匹配，最多 8 行；"当前目录"只从元状态引用推（`focusRef` 优先，再到 `sidebarSelection`；文件夹取 id，文件取父路径），面板不自己保存第二份当前目录。
- 没定位到目录时如实说「先在左侧选择或打开一个文件夹」；命令与文件都无匹配说「没有匹配的命令或文件」。

## 执行与失败

- 单击/回车执行。忙碌守卫在基座（同刻只跑一条命令）；成功即关面板，失败**留在原地**显示 `lastError()` 的中文说明，不静默吞掉、不假装成功。
- 文件行选中发 `sidebar:selection:changed` + `focus:changed` 两个引用事件：目录引用让文件浏览栏导航进去，文件引用落到其父目录并在详情区显示自己——不跨插件伸手改别人的内部状态。
- 重开面板时清空查询、刷新当前目录文件（迟到的列表结果只认最后一次）。

## 键盘与权限纪律

- 全局只有基座命令服务**一个** window keydown 监听（惰性安装、`capture: true`）；可输入控件里只派发带 Ctrl/Alt/Meta 的和弦——打字 `p` 不会触发按字母的键位，Ctrl+Shift+P 在地址栏里照样可用。
- 注册要求 manifest `commands.register`；`provide` 单独授权，未授权调用整体拒绝并告警——`plugin-dev-slot-harness` 的故意越权是这条的运行时证据。
- 畸形快捷键（如 `"Ctrl+"`）或与已占用键位重复的命令**整条拒绝**并告警——宁可不注册，也不留一条永远不响的死键。
