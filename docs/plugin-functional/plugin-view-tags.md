# `plugin-view-tags` · 标签视图

**状态：现有。** 提供活动栏入口和 `nav-panel:tags`，是标签存储的唯一写者（`db.tags.*`），维护标签及其成员，负责成员级跳转和焦点。

## 功能与交互

- 新建标签；展开/收起标签；向当前焦点添加成员；移除成员；删除标签；重命名标签（保持成员、展开选择与 `seq` 不变）。
- 标签名 trim 后不可为空；同名（大小写不敏感）不重复；同一 path 在一个标签内只能出现一次（kind 只是可刷新的属性，不是成员身份的一部分）。删除标签只删关联，不删除文件。
- 标签列表显示成员数；空集合和无标签状态可区分。成员名截断但悬停可读全名；键盘可展开、创建、选中和删除；破坏性删除需要明确确认或短暂撤销提示。
- 展开/折叠和成员增删局部轻动效；成员焦点转移时反馈选中，但不让标签列表的内部 hover 冒充全局文件焦点。
- 面板三态：载入中 / 就绪 / 存储不可用（附详细信息的悬停说明与重试按钮）；失败的动作提示后重载真相，不静默分叉。

## 数据与交流

- 存储：通用 db 能力的 `db.tags` store（manifest `db.tags.*`，本插件是唯一写者）；kv 行 key = 标签名，value = `{seq, members:[{path,kind}]}`；`seq` 保存创建顺序。首次载入若 store 为空且旧 key `fm.view-tags.v1` 存在，一次性导入后删除旧 key（逐条失败即回滚）；损坏的旧 JSON 只提示、不导入也不删除。见 D26。
- 跨插件读：其它插件经受权能力读——SDK `listTags`/`parseTagRows` 是唯一读路径（file-browser 只持 `db.tags.list`）；写成功后本插件发前端事件 `tags:updated`（无载荷，消费者重查）。不把整个 store 广播出去。
- 成员口径：路径逐字符保留（大小写敏感盘上两种拼写可能是两个文件）；同 path 可存在于多个标签；**不自动清理成员**——文件删除/移动不触发移除，失效引用在点击穿越时如实报错。
- 点击标签发 `sidebar:selection:changed {kind:"tag",id:name,sourcePlugin}`；点击成员发 `focus:changed` 对应 Ref。
- `focusRef` 仅用于“添加选中项目”，须保存其 kind/path；焦点变化不会自动更改成员列表。
- 对标签和成员分别注册右键动作：标签可重命名/删除，成员可跳转/从当前标签移除；空白区域可新建标签。所有动作由本插件校验和写入自己的存储，条件由 `ContextMenuContext.targetKind` 过滤。
