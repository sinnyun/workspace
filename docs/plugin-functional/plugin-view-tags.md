# `plugin-view-tags` · 标签视图

**状态：现有。** 提供活动栏入口和 `nav-panel:tags`，维护标签及其成员，负责成员级跳转和焦点。

## 功能与交互

- 新建标签；展开/收起标签；向当前焦点添加成员；移除成员；删除标签。目标完整功能还包括重命名标签，重命名要保持成员与展开选择一致。
- 标签名 trim 后不可为空；同名（大小写不敏感）不重复；同一 `{kind,path}` 在一个标签内只能出现一次。删除标签只删关联，不删除文件。
- 标签列表显示成员数；空集合和无标签状态可区分。成员名截断但悬停可读全名；键盘可展开、创建、选中和删除；破坏性删除需要明确确认或短暂撤销提示。
- 展开/折叠和成员增删局部轻动效；成员焦点转移时反馈选中，但不让标签列表的内部 hover 冒充全局文件焦点。

## 数据与交流

- 当前存储 `fm.view-tags.v1`，owner 是本插件；结构为标签名到 `{path,kind}[]`。加载时验证并归一化；storage 不可用时本次会话仍可操作。
- 新建/重命名/移除标签、成员操作由本插件更新和持久化，不把整个 TagStore 广播出去。
- 点击标签发 `sidebar:selection:changed {kind:"tag",id:name,sourcePlugin}`；点击成员发 `focus:changed` 对应 Ref。file-browser 不得直接读取此私有 key；标签 chips/筛选需要另建经过权限声明的 tags 查询契约。
- `focusRef` 仅用于“添加选中项目”，须保存其 kind/path；焦点变化不会自动更改成员列表。
- 对标签和成员分别注册右键动作：标签可重命名/删除，成员可跳转/从当前标签移除；空白区域可新建标签。所有动作由本插件校验和写入自己的存储，条件由 `ContextMenuContext.targetKind` 过滤。

## 验收

验证空/重名/空白/重命名/删除、成员重复/移除、文件与目录 kind、损坏 JSON、跨插件不能读私有存储、点击标签与成员分别驱动正确的级联状态。
