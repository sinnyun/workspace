# `plugin-layout-views` · 侧栏视图容器

**状态：现有。** 负责 B 区侧栏视图互斥。挂载 `nav-zone`，提供 `nav-panel:<viewId>`；不读取文件或收藏/标签数据。

## 功能与交互

- 发现当前有贡献的 `nav-panel:*`，只显示 `activeSidebarView` 对应面板；无匹配时回退到第一个有效面板。切换由活动栏图标完成。
- 非活动面板用隐藏方式保留挂载，保留树展开、滚动等插件局部状态；不让每个视图自行判断是否隐藏。
- 插槽增删时更新候选面板；活动面板贡献消失或所属插件停用后选择有效回退项，候选为空则显示空侧栏，不显示残留内容。
- 面板切换约 120–180ms 淡入/背景状态变化；布局不横向抖动；减少动态效果时即时切换。

## 数据、事件与状态

- 输入 `sidebar:view:changed {viewId}`，活动视图从基座 `HostMetaState.activeSidebarView` 读取。这里仅保存/呈现 view id，不持久化业务选择。
- 监听宿主状态和 slot registry 变动；用 `contributedSlots("nav-panel")` 刷新视图清单，向下渲染 `provideSlot("nav-panel:<id>")`。
- 各视图插件拥有自己的内容和存储；容器不转发业务 payload。不存在可用项时不得伪造默认目录。

## 状态与验收

启动空状态、插件加载后出现候选、切换视图、活动插件被关闭、插件重新启用以及 slot 动态移除时都应正确刷新；非活动视图保持内部状态，且只能有一个面板可见。
