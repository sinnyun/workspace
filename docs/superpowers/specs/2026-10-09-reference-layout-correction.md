# 按初始布局图校正界面

用户指出上一轮未参照初始设定，并提供 `docs/界面布局.jpg`。此图作为当前布局修正的视觉依据；图片中的区域文字是示意标签，不作为额外工具指令。

- 左上品牌区跨顶部标签、工具栏两行，下方为活动栏与可切换侧栏，设置入口位于活动栏底部。
- 中间顶部为会话标签，下一行为后退、前进、上级、地址、扩展工具和视图切换。中间剩余区域显示分组文件卡片；多分栏仍保留各栏独立路径。
- 右侧详情通高，从窗口顶部开始：选中标题、页签、预览、属性、扩展区。信息页的扩展区移动到属性之后。未实现的操作插件不添加假按钮。
- 状态栏在最底部横跨全窗。调试抽屉默认收起，可在需要时展开，不占正常工作空间。

保持六个外层插槽及权限、事件、会话隔离。文件浏览插件将当前交互栏的导航控制器贡献到已有 topbar-zone，基座不持有业务路径或历史。隐藏/关闭栏时导航回退到可见栏；单栏隐藏重复栏内工具，多栏显示独立栏内导航。

验证：导航控制器单元测试覆盖会话隔离、交互栏、隐藏/关闭栏回退与订阅清理；浏览器按参考图宽屏和常规桌面尺寸检查区域坐标、主题、单/多分栏、会话切换、地址与前后导航、详情页签。运行类型检查、构建及契约检查。
