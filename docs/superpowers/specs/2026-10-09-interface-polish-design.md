# 文件管理器界面优化设计

用户授权自行规划并完整优化，保留现有大框架。采用冷灰与蓝色的桌面工作台视觉，兼容亮色、暗色及跟随系统。

保留 A 活动栏、B 导航、C 分栏文件浏览、D 详情、顶部工具栏、会话、状态栏及底部调试抽屉。保留插件插槽、权限、事件及会话状态，不增加业务到基座。

统一主题字体、圆角、表面色、边框、焦点环、滚动条。外壳负责共享视觉变量和 Mantine 主题；插件使用带回退的变量并拥有自身语义样式。文件列表与网格增加悬停、选中、键盘焦点，虚拟行高度与视觉高度一致。分栏工具、地址栏和长路径适配窄面板。详情、预览、历史、设置、收藏和标签统一分组与留白，移除面向用户的插槽实现术语。

不升级依赖，不重构数据流，不修改后端或既有生成文件。默认布局状态保持不变。

验收：工作区 TypeScript 检查、外壳与插件构建；浏览器检查亮暗色、列表/网格、1/2/4 分栏、会话切换、详情/设置、侧栏折叠、窄窗口和可见行几何。浏览器使用已有开发模拟数据，原生文件访问由 Tauri 提供。
